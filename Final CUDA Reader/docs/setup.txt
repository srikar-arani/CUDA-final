Install a new card as usual,

The SYSTEM_ID, SYSTEM_SEED, SYSTEM_SERIAL, SYSTEM_ID_LONG
are generated on the first time the system is started.
these information is then written to file:
/app/defaults/device_id.json.
Upon restart, these information are loaded from the file.

If the device_id.json is deleted, a new ID will be generated Automatically.

TO create a SD clone,
delete the device_id file. 
remove wifi password in  /etc/wpa_supplicant/wpa_supplicant-wlan0.conf
